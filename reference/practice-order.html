先练什么，后练什么

依据四张入学卷和作文《My Favourite Pet》。阅读大意不是主战场；输出的准确度才是。

  1. 第三人称单数（进行中）
    作文里密度最高：sleep / go / jump / want / sit / don’t。课：0001 · 表：对照
  2. 动词后面接什么
    like playing、be good at catching。卷面也有 feel like doing、used to play。
  3. It is + adj. + to do
    完成句子 32 题、完形「it’s best for you to…」同一结构。
  4. 固定搭配
    laugh at、go swimming、in the center of、for nothing、at the same time、get back home。
  5. 冠词 a / an / the
    such a useful language；play basketball 零冠词。
  6. 中译英 5 句/次
    把上面结构收进「没有选项提示」的产出。
  7. 阅读细节定位
    Li Na 的时间/地点、NOT / EXCEPT、conference = meeting。大意能力已经可用，后练。

诊断摘要见 learning-records/0001。语法条文不引用 ChatGPT，引用 Cambridge 与 British Council。
